Strategy Overview

This strategy investigates the "Bet Against Beta" anomaly in the Hong Kong market. The core concept involves:

Key Components

  1. Beta Calculation:
    • Uses 12-month rolling regression to calculate stock betas
    • Groups stocks into quintiles based on their beta values
    • Excludes stocks with negative beta values
  2. Portfolio Construction:
    • Long positions in low beta stocks
    • Short positions in high beta stocks
    • Beta-neutral strategy implementation
  3. Data Sources:
    • Stock price data from Yahoo Finance
    • Risk-free rate from HKMA API (1-month HIBOR)
    • Analysis period: 2005-01-01 to 2024-06-30

def load_data(symbol):

    direc = 'data/'
    os.makedirs(direc, exist_ok=True)

    file_name = os.path.join(direc, symbol + '.csv')

    if not os.path.exists(file_name):

        ticker = yf.Ticker(symbol)
        df = ticker.history(start='2005-01-01', end='2024-06-30')

        df.to_csv(file_name)

    df = pd.read_csv(file_name)
    df["Date"] = df["Date"].astype("string")
    df["Date"] = df["Date"].str[:10]
    df['Date'] = pd.to_datetime(df["Date"])
    df.set_index(df["Date"], inplace=True, drop=True)

    df['Risk_free_rate'] = data["hibor_fixing_1m"]
    df = df.resample('M').agg({
        "Open":'first',                       
        "Close":"last",                       
        'Risk_free_rate':"last",
        "Date":"last"
        })
        # We will open position at the first day open price every month
        # We will close position at the last day close price every month

    df['this_month_return'] = (df["Close"] - df["Open"]) / df["Open"]
    df["next_month_return"] = df['this_month_return'].shift(-1)
    df['symbol'] = symbol
    if len(df) == 0:
        os.remove(file_name)
        return None

    return df

Equal Weight Beta Neutral Strategy

This strategy implements a beta-neutral approach by dividing stocks into quintile groups each month. The strategy takes long positions in the lowest beta stocks (Quintile 1) and short positions in the highest beta stocks (Quintile 5). The position sizes are adjusted based on each stock's beta to achieve a zero-beta portfolio.

Strategy Components

  1. Portfolio Construction:
    • Monthly quintile grouping based on beta values
    • Long positions in lowest beta stocks (Quintile 1)
    • Short positions in highest beta stocks (Quintile 5)
  2. Position Sizing:
    • Adjusts position sizes based on stock betas
    • Aims for zero-beta portfolio exposure
    • Uses multiplier to balance long and short positions

Beta Weighted Strategy in Beta Neutral Trading

This strategy enhances the beta-neutral approach by incorporating beta-weighted position sizing. While maintaining the core concept of long positions in lowest beta stocks and short positions in highest beta stocks, the weighting scheme is adjusted based on the magnitude of beta values.

Strategy Components

  1. Position Weighting:
    • For lowest quintile stocks: Lower beta receives higher weight
    • For highest quintile stocks: Higher beta receives higher weight
    • Beta values are capped to prevent extreme weights
  2. Risk Management:
    • Beta clipping between 0.1 and 10 to prevent extreme positions
    • Inverse beta weighting for balanced exposure
    • Normalized weights for portfolio stability

long_position_beta_weighted = pd.DataFrame(trade.loc[trade["rank"]==1])
short_positions_beta_weighted = pd.DataFrame(trade.loc[trade["rank"]==5])

# If date in columns, drop it
if "Date" in long_position_beta_weighted.columns:
    long_position_beta_weighted = long_position_beta_weighted.drop(columns="Date")
if "Date" in short_positions_beta_weighted.columns:
    short_positions_beta_weighted = short_positions_beta_weighted.drop(columns="Date")

long_position_betas_df = long_position_beta_weighted.pivot_table(index="Date", columns="symbol", values="rolling_12_month_beta")
short_position_betas_df = short_positions_beta_weighted.pivot_table(index="Date", columns="symbol", values="rolling_12_month_beta")

this_month_return_long = long_position_beta_weighted.pivot_table(index="Date", columns="symbol", values="this_month_return")
this_month_return_short = short_positions_beta_weighted.pivot_table(index="Date", columns="symbol", values="this_month_return")

# Cap the beta 1t 10 and 0.1 to prevent extreme beta from dominating the portfolio
long_position_betas_df = long_position_betas_df.clip(0.1, 10)
short_position_betas_df = short_position_betas_df.clip(0.1, 10)

long_betas_inverse = 1 / long_position_betas_df
short_betas_inverse = 1 / short_position_betas_df

weights_long = long_betas_inverse / (long_betas_inverse.sum() + short_betas_inverse.sum())
weights_short = short_betas_inverse / (long_betas_inverse.sum() + short_betas_inverse.sum())

long_returns = (this_month_return_long * weights_long).sum(axis=1, skipna=True)
short_returns = (this_month_return_short * weights_short).sum(axis=1, skipna=True)

total_returns = long_returns - short_returns

cumculative_return_low_beta = long_returns.cumsum()
cumculative_return_high_beta = short_returns.cumsum()

Personal Thoughts and Conclusion

Key Considerations

  1. Selection Bias:
    • Exclusion of negative beta stocks limits strategy scope
    • Most remaining stocks follow market trends
    • Limited short-selling opportunities in HK market
  2. Implementation Challenges:
    • Lot size requirements affect position sizing
    • High transaction costs (0.1% stamp duty)
    • Short-selling interest costs not accounted for
  3. Risk Considerations:
    • Larger position sizes required for beta neutrality
    • Multiplied risk exposure in low beta positions
    • Recent performance decline since 2021

While the Bet Against Beta strategy demonstrates effectiveness in the Hong Kong market, practical implementation faces significant challenges. The strategy's performance, particularly in recent years, suggests the need for further research and optimization. Key areas for improvement include:

  • Incorporating negative beta stocks in the analysis
  • Expanding the universe of tradable securities
  • Developing more sophisticated position sizing methods
  • Accounting for market-specific constraints and costs
